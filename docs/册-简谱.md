# 册·简谱（工序卡）

本册＝简谱线的六件事自足卡。共享层只引用不复制，见 docs/01 至 05。

## 1. 适用谱种与判定特征

印刷简谱（阿拉伯数字记谱）及其与歌词、和弦标记的常规混排。路由判据：无谱线，窄小字块多且字形规整；方块字谱（减字／工尺）不进本册。

## 2. 源分档

- 有简谱数字真值（逐音数据）：最高档，直接作核账尺子与交付底稿。
- 无数字源、清晰印刷图：走识别链，本册主路径。
- 低清、手机拍、屏幕截帧：先过图源预筛，可疑与排除型不硬走。

## 3. 引擎与版本位

简谱识别引擎（单旋律印刷谱向），产物形态：识别序列与 MIDI，经转换桥归一为 MusicXML。引擎版本口径统一引用《引擎版本表》。

## 4. 工序步骤

认曲（docs/01）→ 谱种路由 → 图源预筛（免模型冒烟：切分与列宽统计，分可用／注意／排除）→ 引擎识别出序列（元数据不确立时按图人工注入调号与速度）→ 转换桥出 MusicXML（桥自带逐事件核对）→ 过闸（docs/04，含本册特有把关）→ 交付（docs/05：简谱腿矢量版式 PDF／PNG 与记号文本，交付后做渲染回读核对）。

## 5. 该线特有把关

- 八度点专查（数字上下的加点决定八度，独立核对，不并入命中）。
- 同音相邻合并显式待裁（圆滑线或延音线歧义，引擎主动列清单，能配歌词对位时以对位收敛）。
- 粘连符号核对（升降号与数字贴印成块处，取数与保音分开记）。

## 6. 诚实边界

单旋律印刷简谱可用，好图读数好、常规图有缺行缺字，一切坏行有警告明示。和弦圈号、双音叠写等复杂版式超出单旋律引擎能力，属排除型，拒判或转人工。低清源按档披露区间，不做超能力承诺。

## 7. 常见故障与换源动作

- 调号或速度读错：人工一分钟注入（按图读值），不修图不改源。
- 宽列粘连警告：逐处人工裁看，必要时换更高清图源。
- 行切破碎（带背景装饰、密排）：属预筛排除型，换图源。
- 引擎无产出：核输入目录仅含受支持图格式；仍失败则如实拒判并说明换图要求。
