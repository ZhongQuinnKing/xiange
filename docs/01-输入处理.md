# 01 输入处理：任何东西进来，先认曲

## 原则

低质量输入（糊图、手写、截图、哼唱、一句话）**不做转谱**。它只承担一个任务：**认出是哪首曲子**。
认出来之后，谱从"搜索"来，不从"抠图"来。**输出质量与用户给什么无关。**

## 认曲流程

1. 提取线索（有什么用什么）：
   - 曲名字样（图上标题、文件名、用户原话）
   - 歌词片段（图上带词就读；中文 OCR 可用本机 tesseract）
   - 调式调性、速度标记（如 ♩=68）
   - 歌手、作者
   - 音频（哼唱/录音）：暂无指纹识别，转"歌词搜/请用户说歌名"
2. 判断置信：
   - 曲名明确 → 直接进 02
   - 只有歌词或旋律线索 → 用采诗搜歌词片段定位歌名
   - 仍不确定、或同名多首 → **问用户**，问最少：
     - "这是谁唱的？"
     - "还记得一句歌词吗？"
     - "什么调、什么节奏？"
3. 认曲产出：**歌名 + 版本线索**（原唱是谁、用户想要哪个编配）→ 进 02 源获取。

## 常见情形

- 只给一句话"来一份某某歌的谱" → 直接进 02
- 给音频 → 先认曲 → 进 02；音频留着，后面验证用（对拍）
- 给的图很清晰（印刷高清）→ 认曲后它本身也是一个候选源，和搜到的放在一起比
