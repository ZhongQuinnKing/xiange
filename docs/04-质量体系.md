# 制谱质量闸门（旧错误不再出现）· 2026-10-10 立

纪律：以前那些错误谱的问题必须解决、不准再出现。
本表逐条对账：旧错误类型 → 拦截机制。

## 八类旧错误 × 拦截机制

1. 凑数＝发明数据（不确定就编满拍）→ 铁律：不确定只许标 [?]，绝不猜；宁可交"这段没读准"
2. 手写谱读图错（错八度/漏音/时值错）→ 手写读图线已停；读图今后只作辅助、不作依据
3. 音频转谱乱就交付（"我落泪"那批"连乐谱都称不上"的）→ 音频数据降级为"交叉参考层"，
   主路＝印刷谱机读；音频绝不单独当成品
4. 时值不核对 → 硬自检：每小节双手时值各＝4.0，不过关回看原图
5. 调号信页面元数据 → 调性用数据校准（与音频对拍扫描），不信标注
6. 没核对就交付/入库 → 出库闸：逐音核过原图才许标"已验证"；没核的一律标"待核对"
7. 不渲染对比 → 渲染成图与原谱并排/小节级放大核对（必过步骤）
8. 编配跑在复刻前（v4 教训）→ 顺序定死：原版复刻过关 → 才谈编配

## 出库三步（任何谱交付/入谱库前）

1. 过四道自动关：机器交叉（≥2 源）→ 时值结构自检 → 多源一致性 → 低置信标记 [?]
2. 逐音核对：与原图小节级放大核对（人工关，必过）
3. 状态标记：已验证 / 待核对，没核完绝不让它冒充成品

## 诚实边界

绝对零错误做不到（既定原则）；"错误可见＋不冒充成品"做得到。
没核完的谱＝"待核对"三个字，绝不含糊，这就是"不准再出现"的机械保证。

## 符号层回填的边界（实测）

从谱图读符号（连音、力度、踏板）存在读图天花板：**区间能定，精确起止有时定不了**。
处理纪律：**有把握的插入，没把握的列"待核清单"**（随交付附上，供人工顺手补）。
提示：**若源本身是带符号层的数字格式（mscz／MusicXML），符号层自带、无需回填**，选源时优先。

## 工具现况（2026-10-10 补）

- 统一评价引擎（tools/omr_eval.py）：真值核账的标准工具。四级度量（音高／时值／结构／符号），输出标准报告卡（三色账＋口径标注）。引擎输出与真值（双读 md／简谱／MusicXML）比对走它，别的口径不再用。自测：tools/tests/test_omr_eval.py（五场景，随时复跑）。
- 乐理错检器（tools/theory_check.py）：识别结束后的自动关。声部交叉／平行五八度／跨度过大（默认上限大十三度可调）／声部密度骤降／小节时值，输出乐理体检卡（严重／轻两级）。自测：tools/tests/test_theory_check.py（六病例，随时复跑）。用法＝共识融合后出一遍，严重项修完才算过闸。
  - 声部密度骤降（E5，2026-10-10 加）：持续和弦（≥2 拍、≥2 音）之后紧跟的发音点音数骤降 ≥2（按音高去重计）＝该手内声部成组缺失。补的是音类级检查的盲区：滚奏／柱式和弦丢内声部时，和弦组成音类常被另一声部或另一八度顶班（实例《失眠》m5/m9 的 E3 由右手 E4 顶班，音类级放行）。属启发式，合法织体切换（3/4 舞曲"和弦＋单音"收句）同样触发，列为"轻"（待裁，不作自动改谱依据）。
