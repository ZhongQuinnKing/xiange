# 05 交付标准

## 分级承诺（2026-10-10 按实测校正）

| 输入 | 承诺（按实测口径校正） |
|---|---|
| 数字源 | 直通，内容与呈现都可信 |
| 高清印刷谱（1000px 以上、清晰） | **推荐**：内容级几乎全对（逐节音高集合一致）；呈现细节（连音线与事件切分）有少量记账差异，逐处标注 |
| 视频截屏源（720p 级） | **有条件可用**：旋律骨架可靠；内声部与节奏需逐处核（标"待核"）；个别图可能无法处理，会明说 |
| 最低档视频源（480p 级） | **不建议**：质量比中档提升有限，而处理失败概率明显更高——正确动作是换更高清的源 |
| 低于最低线 | **拒收**：明说"这张做不了，请换更好的图"，不硬做 |

口径说明：上表为定向实测校正后的定性承诺（"内容级"指音高集合层，"呈现级"指同拍事件与时值写法层）；两层的数字分开看，不混报。

## 交付物

- 乐谱文件：MusicXML 为数据底，PDF 为成品
- **置信标注**：逐处标"可核／待核／存疑 [?]"。"某个准确率数字"不如"每处标出能不能信"
- **来源与链条记录**：源从哪来、过了哪几道关、谁核准的

## 语言纪律

- 没核过的标"待核对"，核过的才许写"已验证"
- 拒收时说清三件事：为什么不行、怎么给更好的输入、拒收不是失败是保护
