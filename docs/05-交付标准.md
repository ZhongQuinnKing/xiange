# 05 交付标准

## 分级承诺（目标线，逐级以实测兑现）

| 输入 | 目标 |
|---|---|
| 数字源 | 100%，直达 |
| 高清印刷谱（1000px 以上、清晰） | 可用线 95% |
| 普通印刷谱（720p 级、有遮挡） | 90% 上下，遮挡处标 [?] |
| 最低达标线 | 80% 上下，全处低置信标注 |
| 低于最低线 | **拒收**：明说"这张做不了，请换更好的图"，不硬做 |

## 交付物

- 乐谱文件：MusicXML 为数据底，PDF 为成品
- **置信标注**：逐处标"可核／待核／存疑 [?]"。"某个准确率数字"不如"每处标出能不能信"
- **来源与链条记录**：源从哪来、过了哪几道关、谁核准的

## 语言纪律

- 没核过的标"待核对"，核过的才许写"已验证"
- 拒收时说清三件事：为什么不行、怎么给更好的输入、拒收不是失败是保护
