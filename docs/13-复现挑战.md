# 13 复现挑战（公开基准样例包）· 2026-10-13

examples/bench 的十一首合成谱例已定为回归基准。欢迎任何人在自己的环境复跑，把结果贴回来。

## 三步

    git clone https://github.com/ZhongQuinnKing/xiange && cd xiange
    bash install.sh core
    python3 tools/bench_run.py

## 预期（定版快照）

- 十首干净件：记谱 严0轻0；乐理 严0轻0；体检 0。
- 一首瑕疵校准副件（基准11）：记谱 严1轻0；乐理 严0轻1；体检 0。
- 逐件精确计数见 examples/bench/预期.json。跑出来与此不一致本身就是有价值的报告。

## 提交方式

用仓库 issue 模板「复现报告」：贴 bench_run 全文输出、Python 版本与系统。差异会被记入版本记录。

## 口径

本包验的是「流程可复现」：谱例全部合成自造、不含任何第三方谱面，不承诺准确率数字（数字口径见 docs/06）。
想先验检器判据本身：examples/blind 盲测包（干净与瑕疵混排，先自己判、再对答案）。
