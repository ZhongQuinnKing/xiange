# 引擎版本表 · 2026-10-13

用途：钉死每个引擎的版本与位置。复现性事故的两个常见根因是「当时最新」和「忘了换过什么」，本表防这两样。任何引擎升级与换版，在本表登记一行日期与原因。

分节按线：五线谱线、简谱线、六线谱线、古琴线、音频线、储备。许可不明的引擎不进发布链。

## 五线谱线

### oemer

- 用途：五线谱识别（高清备份位）
- 版本：0.1.5
- 许可：MIT
- 产物形态：MusicXML
- 最近验证：2026-10-10
- 已知失败模式：低清行整行失败；大页内存吃紧（同刻一件）
- 复现注意：OpenCV 5 形状差异需修补（随环境；升级会丢补丁，重装前先导出）

### SMT（Sheet Music Transformer）

- 用途：五线谱识别（骨架位，质量第一）
- 仓库与提交：github.com/antoniorv6/SMT @ 20d8240
- 权重：PRAIG/smt-fp-grandstaff（必须用此版；新命名与代码匹配，旧命名权重不通用）
- 许可：代码 MIT；权重 MIT（均已核）
- 产物形态：bekern 文本；转 MusicXML 时补双声部表头（kern 族）后由 music21 解析
- 最近验证：2026-10-11
- 已知失败模式：低清与超宽行会出「死行」（运行无输出、日志冻结，须重跑或换路）；过窄或过高的碎片行不切、不收
- 复现注意：系统级模型，输入宜为单个谱表系统

### homr

- 用途：五线谱识别（佐证位；全页直读、天然去重）
- 版本：uvx --from 'homr[cpu]' homr；release tag benchmark（2026-06-18）；实测 0.6.2
- 许可：AGPL-3.0（按用户自装工具引用；不随包分发）
- 产物形态：MusicXML
- 最近验证：2026-10-11
- 已知失败模式：个别整页超时（重跑或换路）
- 复现注意：uvx 默认取「当时最新」，复现须显式锁版本；模型权重需手动下载（release 的 onnx_checkpoints 三件：segnet_308／encoder_331／decoder_331），复制进包内路径后零联网可跑

## 简谱线

### OrpheusNet

- 用途：简谱识别（单旋律印刷谱向）
- 仓库与提交：github.com/Akane0721/OrpheusNet @ 20da0ed（2024-06；此后停更）
- 许可：MIT（代码与权重同授权）
- 产物形态：识别序列与 MIDI（经转换桥归一为 MusicXML）
- 最近验证：2026-10 上旬
- 已知失败模式：仓库停更；换字体、换版式的域外件回退明显；输出非 MusicXML
- 复现注意：锁 CNN 档（CNN_middle＋CNN_meta 约 14MB）；VGG 权重缺，别走；本地 patch 均留 .orig 备份

## 六线谱线

### TabOMR

- 用途：六线谱识别（端到端出 MusicXML）
- 仓库：github.com/christelle5/tabomr；权重随库（models/：YOLOv8s best.pt＋CNN cnn2_N2.keras）
- 许可：MIT（代码与权重全清；配套数据集 CC-BY-NC，整合时分离处理）
- 产物形态：MusicXML
- 最近验证：2026-10 上旬
- 已知失败模式：版式不符即失败（时值符须在谱表下方、符号印刷清晰、手写不支持）
- 复现注意：①权重 .keras 为 Keras3 格式，须 keras3 3.3.3＋KERAS_BACKEND=torch＋TORCHDYNAMO_DISABLE=1 加载（Intel Mac 的 TF 路不通）②版本锁：numpy 1.26.4／scipy 1.11.3／ml-dtypes 0.4.1／opencv-python 4.10.0.84（新包全要 numpy2，混装即崩）

## 古琴线

### guqin-auto-dapu

- 用途：古琴减字谱整页识别（图到减字序列、弦徽音高、MIDI）
- 仓库与提交：github.com/atsu-4444/guqin-auto-dapu @ 14c9c26；权重随库（YOLO11n＋EfficientNet-B0＋SVM，约 62MB）
- 许可：AGPL-3.0（按用户自装工具引用；不随包分发）
- 产物形态：减字序列＋MIDI（经转换桥归一）
- 最近验证：2026-10 上旬
- 已知失败模式：对空音高存在弦位继承回退，单看 MIDI 会掩盖音高表缺陷（核账要表列与 MIDI 两头对）；仓库自带音高表有已知违例，使用前先核修
- 复现注意：①须关断自带外呼开关（否则默认调外部接口外发曲名与识别序列）②无命令行入口，需自写调用脚本
