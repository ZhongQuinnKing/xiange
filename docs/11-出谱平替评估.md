# 11 出谱平替评估：MuseScore 4（第一轮实测）· 2026-10-13

背景：流水线里 Dorico 走手工精排（docs/05）。用户侧常见替代是 MuseScore Studio 4（免费开源）。本页记第一轮实测事实，不做替换决定；不兼容处照实列。

## 实装件

MuseScore Studio 4.7.5（官方 DMG 装成；本机 brew cask 定义异常，绕行，留痕于安装日志）。

## 实测（本机，2026-10-13）

1. 命令行无头转换可用：
   - MusicXML 到 PDF：一条命令直出（13 小节两手小样，约 53KB）
   - MusicXML 到 MP3 试听：直出（试听链已接）
   - MusicXML 往返（导入再导出）：音符级无损（源 217 音，回读 217 音，声部数一致；源中一处符杠缺失在往返后保持原状，不代改）
2. 与本包五线谱腿（vv_render／export_pack）分工：
   - 本包腿：A4 多页、批量、脚本化，产 SVG／PNG／PDF 三件，字体走 OFL 内嵌（发布口径）
   - MuseScore：交互精排与试听渲染；命令行能转换，版式控制与批量命名的细度不及脚本链
3. 已知差异（第一轮）：
   - 版式细节（间距、系统断行）由各自引擎决定，两链出稿版式不同；以哪条链为准按件定
   - 其转出 PDF 的字体嵌入随 MuseScore 自带字体；对外发布前照 export_pack 口径过字体闸
   - 自由速度记谱、古谱符号等超出其常规范围，超范围即不用

## 结论（第一轮）

- MuseScore 4 可作：试听渲染链（已用）＋用户侧出谱替代（Dorico 免费平替的方向成立）。
- 本包脚本链仍是发布口径主链；MuseScore 定位为补充，不做替换。
- 下一步（候批）：取 2 至 3 件真实件做同源双链版式对比，差异清单化后再谈深度兼容。
