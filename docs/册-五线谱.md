# 册·五线谱（工序卡）

本册＝五线谱线的六件事自足卡。共享层（输入处理、源获取、质量体系、交付标准）只引用不复制，见 docs/01 至 05。

## 1. 适用谱种与判定特征

印刷、影印、照片版五线谱。路由判据：页面或行带检出规则谱线串，谱线数为 5 的倍数（多条谱表连排同判）；六线谱、简谱、方块字谱（减字／工尺）不进本册，走各自线。

## 2. 源分档

- 有数字源（MusicXML／MIDI 等可核文件）：源头最优，直接转换核对，不做识别。
- 无数字源、源图质量好（印刷级）：走引擎链，本册主路径。
- 无数字源、源图质量差（照片、低清）：预期区间如实披露，读不动的行诚实拒收，不硬出。

## 3. 引擎与版本位

- 快路整页引擎（全页直读，多声部稳健）：首选。
- 行级骨架引擎（按谱表系统逐行识别后拼合）：整页尺寸不适配时的第二路径，须核行间小节序连续。
- 稳路引擎（慢而稳，可断点续跑）：作备位。
- 产物形态：MusicXML（行级引擎出 kern 语系，过转换层归一）。引擎版本口径统一引用《引擎版本表》，本卡只写名与产物形态。

## 4. 工序步骤

认曲（docs/01）→ 谱种路由 → 源分档与获取（docs/02）→ 引擎出谱（本册三路按图况择一）→ 转换层归一 MusicXML → 过闸（docs/04：乐理关、记谱关、报告卡、人工关）→ 交付（docs/05：五线谱版式 PDF／PNG／SVG）。

## 5. 该线特有把关

- 八度差单列（音高对而八度错不并入命中，单列呈现）。
- 多声部件逐声部核对归属（防止跨声部串配）。
- 行级引擎产物核对行间连续（小节序、谱号调号随行携带）。

## 6. 诚实边界

印刷件最稳；照片与低清按档披露预期区间，宁保守勿夸大。单旋律与旋律加伴奏覆盖好；密集四声部织体上各引擎强弱有差，选路以实测为准。全部读数带口径，不承诺无错，承诺错误可见。

## 7. 常见故障与换源动作

- 引擎崩溃或超时：换另一路引擎；或降分辨率重试；行级引擎可分段重跑。
- 缺页或图源不清：补图源，或换官方谱源。
- 读缺声部：改用全页直读类引擎。
- 反复不稳：回退到源分档上一步，先解决源，再谈识别。
