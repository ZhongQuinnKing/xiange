# 07 已知局限（如实边界）· 2026-10-13

一页集中，先看这里再看承诺，避免误解。三类核心局限，外加两条常见边界。

## 一、手写谱不进识别线

识别线（转谱）只做印刷体。手写谱（含工整手抄）不承诺转谱：现有识别引擎做的是印刷体，手写属另一条技术路线。

手写可以当「线索」用：低质输入（糊图、手写、截图、哼唱、一句话）只承担认曲任务（见 docs/01）；认出来之后去找印刷版源再走转谱。

## 二、低清拒收

清晰度不达线（糊图、低分辨率、大面积反光）拒收，不硬做。硬做出来的谱错误不可控，交出来比不交更坏。拒收线与分级承诺见 docs/05。

## 三、符号层天花板

连音线、断奏、力度、踏板、反复记号等符号层，现阶段的识别引擎普遍不认，为工序化回填为主（边界实测见 docs/04）。符号层成绩单列，不与音符层混报（口径见 docs/06）。

## 四、跨域会回退

单域验证过的线，跨域（换曲目、换字体、换版式、换质量）质量会明显回退。这是评测常识，不是本包独有缺陷，但报数时必须标「域内／泛化」（见 docs/06）。

## 五、简谱件限单声部

简谱腿现限单声部；多声部件走五线谱（不适用即豁免，不算缺件）。

其余边界随各件如实标注：没核过的一律标「待核对」，不标「已验证」（出库闸见 docs/04）。
