# 12 故障排查（常见坑速查）· 2026-10-13

先跑一条命令：`python3 tools/xiange.py doctor`。它直报缺什么，并给出对应修复命令。以下按症状查。

## Python 版本不对

症状：pip 安装报语法或构建错误。处置：需要 3.10 及以上（参考环境 3.11）。例：`conda create -n xiange python=3.11`。

## music21 装不上 / 导入失败

核心档依赖。处置：`bash install.sh core`（或 `pip install -r requirements.txt`）。仍失败先核 pip 源与 Python 版本。

## playwright 浏览器缺失（简谱腿）

症状：deliver_dolce 报缺依赖或浏览器。处置：`bash install.sh browser` 后 `python -m playwright install chromium`；简谱腿另需本地 Dolce 服务（见工具头注）。

## 外部引擎路径未配置（SMT／homr／oemer）

症状：`tools/engine_runner.py` 报环境缺失（rc=3）。处置：SMT 由 `SMT_ROOT` 指向仓目录（接入节见 docs/03）；homr 走 uvx（`uvx homr --help` 自证）；oemer 独立 venv。引擎版本与权重口径见 docs/引擎版本表；doctor 会逐项给提示。

## 中文字体缺失导致渲染乱码

症状：中文标题或歌词变方框。处置：字体随包在 `assets/fonts`（OFL 许可）；缺则补回该目录。交付字体口径见 docs/05。

## 其余速查

- 渲染档报 verovio／cairosvg 缺：`bash install.sh render`。
- 输入路由档报 cv2 缺：`bash install.sh vision`。
- 想一条命令自证安装：`python3 tools/xiange.py selfcheck`。
- 外部引擎非 pip 依赖，属按需接入，见 docs/03 与 docs/引擎版本表。
