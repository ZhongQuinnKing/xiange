# 曲式（知识库·第三域）
（最后修订：2026-10-13｜核验制：按月复核，见 _总纲；未核处标 [?]）

本域管一首曲子的"建筑学"。看谱分析要切段落、编配前要画结构蓝图、复刻时判断重复与跳转，都从这里取用。依据：斯波索宾《曲式学》（张洪模译）、吴祖强《曲式与作品分析》、姚恒璐《音乐结构逻辑》、钱仁平《"三部-五部"：结构辨析与曲式归类》（音乐研究 2021）、流行歌曲结构通行体系。不确定处标 [?]。

## 一、总框架

### 底层逻辑

音乐结构的四个动作：统一、对比、变化、回归。任何曲式都在这四个动作上做文章。一段主题陈述（统一），中途变化或引入对比，最后回归原题。听见"回来了"，就听到了曲式。

### 曲式的三重身份（本库怎么用它）

1. 分析工具：拿到曲子，切出结构，读懂意图。
2. 写作模具：作曲时选一个框架再往里填。
3. 编配蓝图：改编时按段落设计织体与力度阶梯（六步法第 3 步用的就是它）。

### 曲式功能（各段落承担的角色）

呈示（初次陈述）、展开（发展裂变）、再现（回归）、连接（过渡）、补充（收尾）。段落是砖，功能是砖的用法。同一段素材可以当呈示也可以当再现，看位置与意义。

（功能实例：奏鸣曲式的连接部是"连接"功能的标本，使命是从主部调性走到副部调性，同时把两种性格接起来；流行歌的 pre-chorus 是"连接"的现代面孔，使命是把主歌的能量推到副歌。分析流行歌时把 pre-chorus 按"连接功能"读，段落的价值立刻清楚。）

## 二、结构单位（从小到大）

### 动机（motif）

最小的一口气含特征的结构单位。短小，含特征音程或节奏型，是全部发展的种子。贝多芬第五交响曲开头四个音就是标本级动机。写动机两个要求：特征鲜明（一听记得住）、可发展（能转位、扩缩、变形）。

### 乐节与乐汇

动机组合成乐汇（副动机），再组合成乐节（约两小节的量）。这两个层级在分析里用得上、写作里不必刻意规划，属于"看得到就标"的中间态 [?]。

### 乐句（phrase）

旋律的一次完整呼吸。典型四小节，但术语本身是"功能定义"不是"小节定义"：有起点、有推进、有收束点（哪怕收束是逗号）。

### 乐段（period）

两个乐句的呼应。第一句问（收在属或其他不稳定处），第二句答（收主音）。这是"二分性"结构的最小完整体。

乐段的分类维度：
- 方整/非方整：两乐句等长（各四小节）为方整；不等长为非方整。
- 收拢/开放：收主音为收拢（闭合）；收在属等为开放（悬着）。
- 转调乐段：第二句转入新调。
- 复乐段：两乐句各自本身又带重复或附加，规模扩一档。

### 扩充与补充（辨析重点）

- 扩充（extension）：结构尚未完成时，内部延展，通常不长于结构本身的规模。听感是"这句话还没说完"。
- 补充（supplement/codetta）：结构已经完成收束后，附加的重复或收束加固。听感是"已经说完，又补了一句"。

判断法：找结构本该收束的点，收束之前多出的＝扩充，之后多出的＝补充。流行歌副歌最后重复半句，多是补充。

## 三、动机工作操作法（写作向）

§二把动机定义成"发展的种子"。这一节写种子的种法：怎么造、怎么变、怎么自查。规则驱动与动机驱动的分别就在这里——前者往模具里填空，后者从一颗种子长一棵树。依据（2026-10-10 采诗检索）：勋伯格《作曲基本原理》主题构造部分；勋伯格论勃拉姆斯与"发展性变奏"；"固定乐思、主题变形、主导动机"三手法对比文；贝多芬第五交响曲第一乐章动机发展的通行分析。文献落点见本节末。

### 动机的生成三法

1. 特征音程。动机的指纹先落在音程上，不落在音的数量上。命运动机（贝五）说穿了就是"三下同音重复＋下行大三度"，一个节奏加一个音程，话说完了。写作时给自己挑一个"不正常"的音程当骨架：半音叹息（下行小二度）、大跳（六度以上）、增四度，或者带调式色彩的三度（小调的上行小三度）。检验法：把动机移到别的调，特征还在不在。
2. 特征节奏。节奏是动机里最容易被记住、最抗变形的东西。长短组合定下来（短-短-长是命运动机，长-短-短是舞曲常态），音高随和声换，节奏不动。发展性变奏的第一步常是"节奏留、音高变"，换了皮还认得出骨头，靠的就是它。
3. 音型化。把动机本身投成伴奏音型或织体：主题里的三音细胞，转手铺成左手的分解和弦、右手的衬腔，甚至低音线条。主题变形的通行定义把手法范围明确扩到节奏、节拍、速度、织体（百度百科·主题变形词条口径）；勃拉姆斯的发展性变奏走得更远，把动机埋进内声部与伴奏里。好处是材料自给自足：全曲听不到第二种种子。

三法常配合：音程定基因，节奏定面貌，音型化定它在织体里的第二身份。

### 变形六法（操作定义与辨认度）

1. 倒影：音程方向反转，上行改下行、下行改上行。调内倒影（保持调式音）与严格倒影（音程数精确镜像）两种，写作多用前者。
2. 逆行：音序反向，末音到头来当首音。纯逆行听感上常认不出，实战多与移位、改音合用，写成"隐逆行"。
3. 扩缩：时值放大（扩大法：八分变四分、四分变二分）或缩小（紧缩法）。动机性格随速度感变化，扩大常带庄严，缩小常带急促。一条纪律：一段里让扩大与紧缩各出场至少一次，节奏张力自己会长出来。
4. 移位：整体搬高搬低，连做两次以上就是模进。模进是统一段落最省力的工具，也最容易被听出偷懒，所以常给它配一个变化（结尾改音、换和声、改节拍位置）。
5. 装饰：骨架音加外音（经过、辅助、倚音），或给动机加前缀后缀。勋伯格的说法是生出"动机形式"——同一动机的各种近亲。装饰要节制，骨架音程得让耳朵还摸得到。
6. 截断：只取动机的头（或尾）当新材料，反复、叠置、与另一截拼接。贝五第一乐章发展部是标本：四音动机被断裂、错位、反行处理，碎片自己成了动力。截断的反面是拼接，把两个来源不同的碎片焊成新句，展开部的常客。

辨认度纪律：每次变形后自问"骨架音程与特征节奏，至少还留着一个吗"。两个都丢，动机就死了，全曲散成拼盘。

### 发展自查表（写完一段过一遍）

| 查项 | 过尺标准 |
|---|---|
| 可追踪 | 每句都指得出用了哪一法；写不出＝动机工作缺位 |
| 远近搭配 | 至少一次远变形（倒影/逆行/截断）加一次近变形（移位/装饰）同场；全近保守，全远散架 |
| 统一性 | 抽掉动机，全曲还成立吗？还成立＝动机只是贴纸，不是种子 |
| 张力三轨 | 力度、音区、密度（每拍音符数）各有起伏，不留平线 |
| 记忆点 | 完整形态在关键位置（开头、高潮、收尾）到场；只听碎片不见原型，不叫发展，叫没交代 |
| 冗余 | 同一变形连用三次以上＝机械；删掉任一次，前后断裂吗？不裂则多余 |
| 收束 | 变形最终落回原型或它的明确变体，让耳朵"回家" |

（本表管发展过程，§十自检清单管段落切分，分工不重叠。）

## 四、小型曲式

### 一段式

一个乐段独立成曲（或成段）。民谣、圣咏、大部分流行歌主歌段都可以是一段式。

### 单二部曲式（二段式）

两大部分。分类：
- 呈示型二部（A 呈示 + A' 延伸）：第二部是第一部的变体或续说。
- 对比型二部（A + B）：两部对比，B 常带中段性质或再现头。
- 有无再现：B 部末尾再现 A 的材料＝有再现单二（流行歌主歌→副歌后回主歌素材近此）。

### 单三部曲式（三段式）

呈示（A）→对比（B）→再现（A'）。核心是"离开再回家"。
- 有再现单三：A B A。最通用。
- 无再现单三：A B C。三部并置，少见但存在 [?]。
- 对比中段的写法：引入新素材（简单对比）或展开 A 的动机（发展型中段）。

流行语境里的 AABA（32 小节曲式）就是单三部的近亲：主歌主歌桥段主歌，老爵士标准曲半壁江山。

### 单二与单三的辨析

看第三部分：完全回来的 A' 独立成部＝单三；只是续说或收尾＝单二。听感上单三"三段话"，单二"两段话带个尾巴"。

## 五、中型曲式与中介类型（中国教材体系的重要辨析）

三部性曲式向外扩展出几类"中介"结构（姚恒璐《音乐结构逻辑》整理，钱仁平 2021 文辨析）：

1. 双三部曲式：A B A B'（或 A B A' B）。第二部分重复一次，但第二次带变化。
2. 三部五部曲式（单三部-五部）：a b a b a。单三部曲式里把中段与再现部整体重复一遍。
3. 复三部-五部：复三部曲式里重复中部与再现部。两种形态：
   - 两个相同的三声中部：ABABA。
   - 两个不同的三声中部：ABACA，这种最易与回旋曲式混淆。

辨析要点（复三部-五部 vs 回旋曲式）：
- 复三部-五部：强调各部分之间的对比，各大部分独立完整、结构稳定、有收拢性（各自收得住）；通往中部通常没有连接部。
- 回旋曲式：主部多次回归是结构主干，副部处于插部地位，连接部是常规部件。

一句话总结：五部结构里"对比"是主角＝复三部-五部；"回归"是主角＝回旋曲式。

## 六、大型曲式

### 复三部曲式

三个大部，每部本身不小于乐段（常是单二或单三规模）。中部的两种写法：
- 三声中部（Trio 式）：完整独立、调性对比、风格端庄，原意来自巴洛克舞曲的中段三件乐器。
- 插部式中部：不独立、展开性、材料源自首部。

再现部常带变化或缩减（缩减再现尤见于奏鸣曲式，复三部也有）。

### 回旋曲式

主部 R 至少出现三次，副部之间互不相同：R A R B R（五部）为主式，还有 R A R B R C R（七部）。速度多轻快，末乐章常客。与复三部-五部的辨析见第五节。

### 变奏曲式

一个主题 + 若干变奏。类型：
- 固定低音/固定和声的变奏（巴洛克帕萨卡利亚、恰空）。
- 严格装饰变奏（古典）：旋律骨架不变，加花渐密。
- 性格变奏（浪漫以后）：每次变奏换性格，甚至换调式、换体裁。
- 动机变奏：主题被拆解重组，现代语境多。

变奏的灵魂是"变中不变"：听众要能把主题认出来，变奏才成立。

### 奏鸣曲式（大型结构的最高形式）

三大部分：
1. 呈示部：主部（主调）→ 连接部（转调过渡）→ 副部（新调，常为属调或关系大调）→ 结束部。主部副部性格对比是核心戏剧。
2. 展开部：动机裂变、调性游走、张力爬升。素材多取自呈示部，常展开主部动机与结束部。
3. 再现部：主部副部都要回归主调（调性服从），这是奏鸣曲式与二部/三部的分水岭。

变体：奏鸣回旋曲式（回旋与奏鸣合体，末乐章常用）；无展开部奏鸣曲式（慢乐章常用）。古典将呈示部整体反复（再现前跳回）。

### 套曲与组曲

多乐章的组合：奏鸣套曲（奏鸣曲、交响曲）、组曲（巴洛克舞曲组曲、浪漫标题组曲）。

**奏鸣套曲的四乐章布局（古典范式标准形）**：快板（奏鸣曲式，主调）→ 慢板（抒情，常用下属方向或关系调）→ 小步舞曲或谐谑曲（三拍，近主调）→ 快板或急板（回旋或奏鸣回旋，主调，带总结感）。**调性布局是暗线**：小调起、同主音大调收（光明结局）是经典手法（贝多芬第九即此）；中间乐章的调性多用近关系。变体：中间两乐章次序可互换（浪漫以后常见）；协奏曲作三乐章（快慢快）。

## 七、流行曲式

### 基本元件

| 元件 | 中文 | 功能 |
|---|---|---|
| Intro | 前奏 | 定调性定气质，4-8 小节 |
| Verse | 主歌 | 叙事，低能量区 |
| Pre-chorus | 预副歌 | 爬坡，把能量推上去（常 4 小节或两句） |
| Chorus | 副歌 | 记忆点，能量峰值 |
| Bridge | 桥段 | 新材料，破重复，铺垫最后高潮 |
| Instrumental | 间奏 | 呼吸与展示 |
| Outro | 尾声 | 收尾 |

### 常见布局

- VCVCBC（最通用：主歌副歌循环，桥段破局，最后副歌双份）
- VCVCVCC 或 VCVC + 最终副歌升高半音/加和音
- ABABCB（摇滚语境，A 主歌 B 副歌）
- 无副歌型（叙事歌 aaba 变体）

### 华语流行特征

- 副歌是商品核心，一切设计（和声节奏变稀、旋律音区抬高、织体加厚）服务副歌记忆点。
- 桥段后接"升 key 终极副歌"是老练套路（升半音或全音）。
- 主歌-副歌之间的"预副歌"在华语抒情歌里叫"进副歌前的高潮铺垫段"，周杰伦一代作品常见。

### 分析实操（给编配用）

1. 听三遍：第一遍感受，第二遍数段落，第三遍核小节数与和弦。
2. 列表：段落 | 起止小节 | 和声特征 | 织体意图（就是六步法第 3 步的产出物）。
3. 验证边界：段落交界处听"呼吸"（鼓点变化、和声落点、文字分句）。
4. 副歌次数与情绪设计对照：每次副歌的和声或配器变化（大都在最后一次）。

## 八、中国民乐曲式

传统民乐的结构思维与西方曲式不同源，分析时别硬套 [?]：

- 起承转合：乐段级经典四句体（起句、承句、转句、合句），"转"处常引入新材料或调式变化，"合"处回归。民歌分析基本盘。
- 板式变化体：由"散-慢-中-快-散"的速度板块组合成曲（戏曲与器乐化曲目，如《五梆子》类）。速度即结构，与西方"曲式即主题关系"思维对照鲜明。
- 循环体：主题不断回归，中间插不同段落（形式上近回旋，但循环单位常是"曲牌"）。
- 变奏体：旋律加花变奏为主（板式变奏、加花变奏）。
- 联曲体：多个曲牌序连（昆曲、说唱的结构基础）。
- 板式实例（京剧，板式变化体的大宗）：基本板式一组，原板（中速基本板）、慢板（抒情，一板三眼）、快板（急促）、流水（快板变体，西皮流水常见）、散板（自由节拍）、摇板（紧拉慢唱，伴奏快而唱腔宽）、导板（散板式的段落引导）。**一段唱腔由板式组合成结构**（如导板→慢板→原板→流水→散板），速度与板眼即结构，与西方"曲式即主题关系"的思维对照鲜明。板腔体（板式变化）与曲牌体（联曲）是戏曲音乐的两大体制，京剧属前者，昆曲属后者 [?]（曲目级谱例按需补）。

给民乐改编钢琴时：段落的板式逻辑（速度层次）比西方曲式标签更值得保留。

## 九、分析实操流程（通用五步）

1. 通听找"回家"点：主音的稳定回归处是结构的地标。
2. 切大段：按对比与回归切（前奏、歌唱段、间奏、尾声；或呈示展开再现）。
3. 切小单位：段内数乐句，标收束点，量小节数。
4. 画图示：用字母（A B A'）或功能术语（呈示/对比/再现）画层级图。图示的层级是结构判断的最终证据。
5. 验：对照调性布局与主题关系复核（大结构通常伴随调性手势：转调即转折）。

图示规范：字母本体表同一材料（大写代表独立部，小写代表乐句级）；加撇表变化（A'）；不同字母表对比（B）。数字下标可标小节数。

## 十、本域自检清单

- 段落切分逐段有依据（收束点、材料变化、调性手势）
- 每次副歌/再现的发生都点数过（漏切多切是分析大忌）
- 扩充与补充分清（收束点前后是分界）
- 中介曲式（五部结构）与回旋的辨析对了（对比为主 vs 回归为主）
- 图式层级自洽（字母与功能可用混合，但一套到底）
- 编配应用：结构表交出一份可直接填织体的（段落 | 小节 | 和弦骨架 | 织体意图）
