# 风格体系（知识库·第七域）
（最后修订：2026-10-13｜核验制：按月复核，见 _总纲；未核处标 [?]）

本域管"惯例库"。风格不是玄学，是一套惯例的集合：和声怎么走、织体怎么铺、节奏什么律动、旋律什么习性、音色什么偏好。识别一首曲子（听出风格取惯例），或生产一段音乐（定风格按惯例写），都从这里取用。覆盖：西洋古典各时期、流行各流派、中国民乐、世界音乐入门框架。世界民族细节：主库在 80 世界音乐专卷（2026-10 补强轮已跑）。

---

## 一、总框架

### 风格的五个维度（分析任何风格都过这五格）

和声（惯用进行与色彩）、织体（纹理与层次）、节奏（律动与重音习性）、旋律（音阶偏好与句法）、音色（乐器与人声偏好）。五格填得出来，风格就说得清。

### 使用法

- 识别：听→过五格→对照本库确定风格标签→取该标签的惯例库用于编配。
- 生产：定风格→按惯例库反向写作（先律动、再和声骨架、再织体、最后装饰）。
- 改编跨风格：同一旋律换惯例库重写（见第七节）。

### 一条纪律

风格惯例是"默认值"不是"牢笼"。偏离有理由就偏离（模仿是学步，创新是走路），但先走稳再跑。

## 二、西洋古典各时期惯例库

### 巴洛克（约 1600-1750）

- 和声：功能清晰，终止式工整；数字低音（通奏低音）撑骨架；I-V 与 V-I 频繁。
- 织体：复调为骨（对位、赋格、卡农），复调与主调切换自然；通奏低音是下层地基。
- 节奏：稳定的持续律动（织体乐器如钟摆），旋律局部自由。
- 旋律：模进（sequence）与序列句法；装饰音是即兴体系（符号只是提示）。
- 音色：弦乐五部、竖笛/长笛、大键琴（清脆颗粒）。
- 标本：巴赫、亨德尔、维瓦尔第。
- 改编要点：保持线条独立（复调域）；装饰音按其演奏约定处理（记谱域）；别把大键琴的颗粒弹成浪漫的绵密。

### 古典（约 1750-1820）

- 和声：透明简洁，I-IV-V 骨架外露；变音少而准。
- 织体：主调为主；阿尔贝蒂低音（分解和弦的古典程式）；清晰对称。
- 结构：奏鸣曲式成熟（曲式域）。
- 节奏：方整，呼吸规整。
- 标本：海顿、莫扎特、贝多芬（早中期）。
- 改编要点：轻巧与清晰优先，力度阶梯对比（不是渐变压满）。

### 浪漫（约 1820-1900）

- 和声：半音化增厚；变和弦与远关系转调常态化；延留与倚音铺内声部。
- 织体：宽琶音、轰鸣八度、大和弦（李斯特式）；踏板深度参与表情。
- 节奏：rubato（借还自由）；大句法（长线条）。
- 旋律：歌唱性极强，句尾常有自由延展。
- 标本：肖邦、舒曼、李斯特、勃拉姆斯、柴可夫斯基、拉赫玛尼诺夫（晚期浪漫）。
- 改编要点：情绪张力优先，踏板与音区配合造"呼吸"。

### 印象（约 1890-1920）

- 和声：平行和弦（平行五八合法化为色彩手法）、九和弦与附加音、全音阶。
- 织体：色彩化分层，音区对比大于功能推动。
- 节奏：流动、水波式律动，重音模糊。
- 标本：德彪西、拉威尔。
- 改编要点：色彩是主角，功能是背景；踏板半踩制造朦胧。

### 20 世纪-现代

- 流派速览：表现主义/十二音（勋伯格）、新古典（斯特拉文斯基中期）、民族主义（巴托克、科普兰）、极简（格拉斯、赖希）、音乐剧场与实验（凯奇）。
- 和声：扩展调性、无调性、音块、复调性。
- 节奏：复合节拍、变换拍子（斯特拉文斯基的节奏革命）。
- 改编要点：先判定具体流派再动手，这个时代"风格"不是一个词能装下的。

## 三、流行各流派惯例库

### 抒情流行（Ballad）

- 和声：4536251 / 卡农进行 / 1564；大七与流行七和弦；副歌前常插副属。
- 织体：分解/半分解主歌，三层次副歌；弦乐铺底（或钢琴模拟弦乐）。
- 节奏：60-80 为主；和弦节奏一小节一换。
- 旋律：副歌音区抬高 + 记忆点重复。
- 编配要点：加法推进，末副歌升 key 或加厚。

### 爵士流行与标准曲

- 和声：ii-V-I 骨架；延伸音（9/11/13）全面启用；替代与转位链。
- 织体：rootless 左手 + 旋律右手；walking bass（三重奏语境）。
- 节奏：swing（三连音化）或 bossa（双拍型）；rubato 空间大。
- 编配要点：voicing 体系（和声域第七节）；节奏律动先立住。

### R&B / Soul

- 和声：小七与九和弦；挂留延迟解决；级进低音线。
- 节奏：切分密集，鼓组的 pocket（时间差的呼吸感）。
- 编配要点：律动重于和声复杂度。

### 民谣（Folk）

- 和声：三和弦为主，诚实朴素。
- 织体：吉他式分解/扫弦移植钢琴（低音-和弦交替）。
- 编配要点：留白，别过度包装。

### 摇滚（Rock）

- 和声：强力和弦（五度）、bVII 借用、持续低音。
- 节奏：节奏型驱动（八分推动），鼓与低音咬合。
- **支流谱系**：布鲁斯摇滚（滚石一代的根基）→ 硬摇滚与重金属（齐柏林、黑色安息日一脉）→ 前卫摇滚（平克·弗洛伊德的剧场化）→ 朋克（性手枪，三和弦造反）→ 后朋克与新浪潮 → 垃圾摇滚（涅槃把另类推成主流）→ 当代另类与独立 [?]（支流细目按需续扩）。
- 编配要点：节奏就是内容；钢琴改编往"节奏钢琴"走（Boogie 拆解）。

### 电子与氛围（Ambient）

- 和声：缓慢变化的层叠；持续低音。
- 织体：音色构成（铺底 pad 与琶音 arp），时间感拉伸；**结构与主题发展无关，靠循环与层叠渐变成形**。
- 子流派速识：House（四拍底鼓为骨）、Techno（机械、极少旋律）、Trance（旋律化渐进）、Dubstep 与 EDM（drop 文化）、Ambient（Eno 命名的氛围一派，无节奏或极弱）、Lo-fi（低保真采样＋爵士和声）。
- **新古典融合（与钢琴直接相关）**：钢琴加电子的当代一路（Ólafur Arnalds、Nils Frahm 系），把古典钢琴语汇放进电子声景——钢琴编配与创作可借其声景思维（延音、混响、极简重复）。
- 识别三指纹：重音模糊、音色大于旋律、时间尺度长（常 5 分钟以上）。钢琴跨界改编时，保留"呼吸感"比补旋律更重要 [?]。

### 中国风流行（华人独有品类，单列）

- **核心公式（曲目级分析结论）**：还是常规流行和弦走向，配上五声性旋律——这是对周杰伦中国风歌曲做过专门分析和声后的一句话总结。风格的关键在旋律的五声性，和声不必"民族化"。
- 旋律：五声性（宫商角徵羽）为骨，偶带清乐七声。
- 和声：三度结构为主（和声域第九节有纵合化备选）；sus、add9 等不解决色彩；常规进行就够用。
- **《青花瓷》（A 大调）实例**：副歌 Ⅳ—Ⅶ46—Ⅲ—Ⅵ—Ⅱ7—Ⅴ—Ⅰ—Ⅴ7/Ⅳ（卡农式下行五度连锁的扩展），重复后第二遍直落一级收尾；主歌 Ⅰ—Ⅵ—Ⅳ—Ⅰ—Ⅱ—Ⅴ，第二句变为 Ⅰ—Ⅲ—Ⅵ—Ⅱ—Ⅴ—Ⅰ。常规和声＋五声旋律公式的标本。
- 配器意象：古筝拨弦、笛声长音、鼓点（民族大鼓）；钢琴改编用琶音模拟古筝、高音区单音模拟笛。
- 节奏：4/4 为主，副歌铺民族打击乐意象。

## 四、中国民乐各乐种惯例库 [?]

- 江南丝竹：支声复调（复调域第八节）；轻快雅致；二胡/笛/琵琶/扬琴小组合。
- 广东音乐：高胡主奏；加花繁密（"加花"二字的发源地之一）；《步步高》一路的欢愉气质。
- 古琴：散板自由（打谱传统）；泛音段落（清透）与按音滑音（吟猱）；音量小、气韵长。
- 古筝：按滑（4、7 的按音处理是中国乐感的精髓之一）；刮奏（上下行白键带式）；摇指长音。
- 民歌色彩区差异（选）：陕北与晋西北，高亢、大跳（信天游、花儿四度以上跳进多）；江南，婉转、级进为主、小腔与装饰丰富；云贵高原，多声部民歌发达（侗族大歌的支声合唱、苗族飞歌）；内蒙古，长调（散板自由节奏＋诺古拉颤音装饰）与短调（规整）两体；西藏，山歌"鲁"高亢辽阔；新疆，木卡姆传统与歌舞性节奏 [?]（各色彩区细目按需续扩）。
- 改编要点：板式与韵腔（速度层次与滑音习性）比具体的和声标签更值得保真。

## 五、世界音乐指引入门（框架；完整归位见 80 世界音乐专卷）

### 印度

- 拉格（Raga）：旋律框架（音阶+上行下行布音规范+情绪定则）；阿拉普（Alap，自由序奏）→ 加特（Gat，循环曲体）；塔拉（Tala）：节奏循环体系（如 16 拍 Teental）。
- 演奏习性：滑音（meend）连接；装饰繁密；持续音（Tanpura 的 Drone）。
- 常用拉格音列（Yaman／Bhairav／Todi／Kafi／Khamaj／Bhairavi 上行下行与情绪）与十母调表：已补，见 80 世界音乐专卷。

### 阿拉伯与中东北非

- 玛卡姆（Maqam）：音阶体系，含中立音程（半降二度/三度，约为 3/4 音）；塔克西姆（Taqsim）：即兴序奏。
- 节奏：循环节奏型（Iqa'）。
- 玛卡姆家族与 Rast／Bayati 音列（含半降音位置）、十二母名录：已补，见 80 世界音乐专卷。

### 印尼甘美兰

- 斯连德罗（Slendro）：五声、近似等分；佩洛格（Pelog）：七声、不等分（大小音程交错）。
- 结构：层叠结构（核心旋律慢速为骨，加花层快速缠绕，大锣标句读）。
- 乐器功能分区与层叠结构细节：已补，见 80 世界音乐专卷。

### 日本传统

- 音阶：都节（含半音双邻音，阴郁）、琉球音阶。
- 乐器：尺八（气声）、筝（十三弦）、三味线。
- 四音阶完整音列（民谣／都节／律／琉球，含音程结构）与曲种：已补，见 80 世界音乐专卷。

### 非洲

- 节奏：复节奏（polyrhythm，多组律动同时）；呼应结构（call and response）与即兴轮转。
- 鼓语传统（信息传递）。
- 曼丁鼓乐编制（敦敦三件／金贝组／沙铃）与节奏家族：已补，见 80 世界音乐专卷。

### 拉美

- Bossa Nova（巴西）：双拍节奏型；半音和声；轻声吟唱感。
- 古巴（Son/Salsa 系）：clave（关键节奏型）为骨。
- 探戈（阿根廷）：切分与顿挫；哈巴涅拉节奏。
- clave 两型文字谱例（3-2／2-3）与弗拉门戈 compás：已补，见 80 世界音乐专卷。

### 世界音乐的编配纪律

先学到"像"（模仿惯例），再谈融合。融合失败的典型是"各取一点皮"（世界音阶 + 西方和声硬贴）。深度融合需要吃透两边的骨（旋律习性 + 律动习性），本轮先存框架。

## 六、风格识别实操（听辨三问）

1. 和声听色彩：大小调骨架？七和弦密度？变音多少？（定位时期/流派）
2. 织体听纹理：复调还是主调？层次几层？（定位古典时期与编制）
3. 律动听重音：稳的还是摆的？重音在哪落脚？（定位流派与地域）

三问之后过五格（第一节），风格标签基本可定。拿不准就标 [?]，别硬猜。

## 七、跨风格改编（进阶应用）

同一旋律换惯例库重写，是检验风格掌握度的实战。示例路径（以一段五声旋律为例）：
- 抒情钢琴版：五声纵合化和声 + 波浪分解 + 慢速。
- 爵士版：加 ii-V 骨架与替代 + swing 律动 + rootless 左手。
- 中国风版：古筝意象琶音 + 笛声单音 + 民族鼓点节奏。
旋律不动，五格全换，风格就变了。改编的质量取决于对目标风格五格的掌握深度。
