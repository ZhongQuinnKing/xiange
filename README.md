# 音乐技能包（工作名）

给主流 AI 用的音乐能力包。姊妹篇：采诗读互联网、拾级陪人、玉尺量文章、本作弄音乐。

练兵项目：《失眠》（~/Desktop/转谱/）。能力都在那里验证，产出全部归本包。
失眠只是"练兵的小项目"，不是成果本身。

## 流水线总览

    任何输入（糊图/截图/哼唱/一句话/数字文件）
      → 认曲：低质输入只是"线索"，不硬做（docs/01）
      →
      ├─ 【数字源直通线】用户持有数字文件（自打/正版/下载）
      │     → 验证三件套 → 直用（最快最准）
      └─ 【搜索线】没有数字源
            → 采诗换源：全网搜高质量谱——弹琴吧/B站链/平台矩阵（docs/02）
            → 源择优：数字源 ＞ 印刷高清 ＞ 印刷普通；手写不用
            → 转谱（引擎链＋多引擎共识，docs/03）
      →
      符号层：从原谱图读取回填（连音/力度/踏板/指法）
      → 精排（Dorico）→ 出谱

每一步都带来源与置信标注。
出库闸：核过的才许标"已验证"，没核的一律标"待核对"。
