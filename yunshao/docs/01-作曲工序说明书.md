# 作曲工序说明书

云韶线（乐正线·三级）·对外精简版

本说明书是本线的工序骨架：从题目或方向到成品四件（MusicXML＋PDF＋PNG＋MP3）。逐步照办即可，每步都有可核查的产出形态。

## 一、读库定风格

按目标风格读知识库对应域（乐理记谱、和声、曲式、风格体系等），规则在手再动手。
定目标：时期、体裁、场合、篇幅。
产出：一段目标定义（给谁、什么风格、什么结构规模）。

## 二、设计蓝图

先设计后落音，一次做全：调式、拍号、曲式、和声骨架、核心动机、力度布局。
产出：可核对的设计清单；配套工具可直接出骨架表：

    python3 tools/工具_骨架表.py 生成器.py

## 三、数据化生成

设计数据单一来源（一处定义），从设计直出乐谱文件；生成带自检（时值、音域、禁则预检），不通过不出文件。
曲面走势可随时核对：

    python3 tools/工具_张力账.py 谱.musicxml

## 四、过检

成品过检器族，逐关跑（仓根 tools/）：

    乐理关：   python3 tools/theory_check.py 谱.musicxml
    记谱关：   python3 tools/notation_check.py 谱.musicxml
    谱面体检： python3 tools/score_doctor.py inspect 谱.musicxml

修整用 notation_fix.py（幂等）与 score_doctor.py fix（自带 .orig 备份）。
核过才标"已验证"，没核的一律标"待核对"。
机器检不到的位置（织体切换处、跨声部抽查）逐处人工核对，核对记录随件落档。

## 五、交付

渲染出谱（PDF／PNG）＋试听（MP3）＋源件（MusicXML）。
成品导出用 export_pack.py（五线谱件＋mxl／mid＋试听＋成品卡＋整包）：

    python3 tools/export_pack.py 谱.musicxml --out 目录 --title 曲名

落盘附说明：设计依据、自校验账、已知偏差与待定项（不确处标 [?]）。

## 附、边界与诚实

- 出品全部原创；AI 出严谨版，艺术判断（风格取舍、标题、速度）归人。
- 不确定处标 [?]，不猜；事实有出处，推测有标注。
- 只处理用户合法持有的输入；不提供受版权保护材料的下载或分发。
