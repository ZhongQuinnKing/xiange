# 移宫 yigong（技能入口）

乐正线·二级

给主流 AI 用的音乐即兴编创能力包。一条能力线，四个活：

| 类型 | 干什么 | 示例 |
|---|---|---|
| 编配 | 给旋律配和声与织体 | samples/送别_声乐伴奏 |
| 伴奏 | 声乐/器乐伴奏版本（多形态） | 同上（A 柱式／B 分解两版） |
| 改编 | 风格重配 | samples/送别_爵士重配 |
| 即兴配型 | 伴奏型设计与谱面化 | samples/茉莉花_即兴配型 |

## 怎么用（按用户来意分流）

- **要编配/伴奏/改编/即兴配型** → 走编创线：读 `README.md` 能力总览与 `docs/01-编创工序说明书.md`，按工序骨架执行（读谱定风格 → 设计 → 配法落地 → 过检 → 交付）；成品过检器族，核过才标"已验证"。
- **要移调/定调** → 仓根 tools/ 两件：`工具_定调.py`（歌者音域 → 可用调＋推荐命令）、`工具_移调.py`（一键移调，含音数守恒与音域对照）。
- **要看要听示例** → `samples/` 五组六件（每件 MusicXML＋PDF＋PNG＋MP3）。

## 核心纪律

- 不确定标 [?] 不猜；事实有出处，推测有标注。
- 成品出库前过检：核过才标"已验证"，没核的一律标"待核对"。
- 只处理用户合法持有的乐谱（自有、正版、公有领域或已获授权）；输入来源合法性由用户自负其责。
- 评价类（哪版更好）：给依据、拆维度，不下裁决。
