给主流 AI 用的音乐即兴编创能力包。姊妹篇：采诗读互联网、拾级陪人、玉尺量文章、弦歌弄音乐。
本包为乐正线·二级（一级弦歌：复刻制谱；三级云韶：独立作曲）。

能力验证：编配、伴奏、改编、即兴配型四类成品全程走通，samples/ 六件均为实跑产物，看谱可弹、开声可听。

## 能力总览

    旋律或需求（一句描述／一段旋律／一张谱）
      → 读谱定风格（调式、结构、旋律特征；目标场景与风格）
      → 设计（和声骨架、织体形态、段落布局）
      → 配法落地（写谱：声部、音区、可弹性）
      → 过检（乐理关＋记谱关＋谱面体检；核过才标"已验证"）
      → 交付（出谱＋试听＋源件）

四类活对应示例（samples/，每件 MusicXML＋PDF＋PNG＋MP3 四件齐）：

| 类型 | 示例 |
|---|---|

## 快速开始

环境：Python 3.11（同仓弦歌参考环境）。本线零依赖件装包即用，其余按档装。以下命令中 tools/ 均指仓根 tools/。

- 零依赖（仅标准库）：记谱两件（notation_check 体检／notation_fix 修复）、移调与定调两件，可直接跑
- 核心档（requirements.txt）：乐理关（theory_check）、谱面体检（score_doctor）
- 出包（export_pack）另需渲染档与浏览器档

一键安装（仓根执行）：

    bash install.sh core        # 检器与修整常用档
    bash install.sh all         # 四档全装（含出包所需）

常用一条命令：

- 移调：`python3 tools/工具_移调.py 谱.musicxml Eb`
- 定调：`python3 tools/工具_定调.py 谱.musicxml A3 E5`（歌者音域 → 可用调＋推荐命令）
- 乐理关：`python3 tools/theory_check.py 谱.musicxml`（声部交叉／平行五八度／跨度／密度／时值）
- 记谱关：`python3 tools/notation_check.py 谱.musicxml`；修整 `python3 tools/notation_fix.py 谱.musicxml`（幂等）
- 谱面体检：`python3 tools/score_doctor.py inspect 谱.musicxml`
- 成品出包：`python3 tools/export_pack.py 谱.musicxml --out 目录 --title 曲名`

## 边界与合规

- 示例旋律为公有领域作品或原创段；本包只处理用户合法持有的乐谱（自有、正版、公有领域或已获授权），输入来源的合法性由用户自负其责
- 诚实纪律：错误可见、置信标注；核过才标"已验证"，没核的一律标"待核对"
- 零出机原则；付费工具自动切平替
